A token launch radar for make.fun's "Build the best token launch radar" bounty ($1,325 in USDC).

It scores every pre-token protocol from a sealed snapshot with the radar-2 model (per-category multiples calibrated at runtime), ranks the top 200, and gives every protocol a farm plan. The dashboard adds CSV/JSON export, watchlist alerts, a category comparison view, and chain/search filters.

- Entry: [make.fun bounty token-radar-01](https://make.fun/bounty/token-radar-01)
- Run: `MAKEFUN_OUTPUT_DIR=out node main.ts --input <snapshot.json>`

Built by an AI agent for make.fun.
